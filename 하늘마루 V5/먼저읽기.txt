하늘마루 V5 — Local + CLIKA

V4를 보존한 별도 버전입니다. V5에는 AWS/Bedrock 요청 코드와 API 키 입력창이 없습니다.
PC가 3D 장면과 로컬 언어 모델을 실행하고, 휴대폰/Android 앱은 영상 수신·조작·NU40 센서 전달을 맡습니다.

이 PC에서 실행
1. 하늘마루_실행.cmd 실행.
2. http://127.0.0.1:8795/host 접속. 실행기가 여는 전용 RTX Chrome 창을 사용하세요.
3. 휴대폰 연결 · IMU · CLIKA 펼치기.
4. LOCAL + CLIKA에 "드론 30대, 2D로 변경" 입력 → 설정 제안 → 값을 확인 → 확인한 설정 적용.
5. 첫 요청에서 모델을 로딩합니다. 응답 생성은 별도 프로세스에서 수행합니다. 2,048토큰 문맥을 사용하며 60초 미사용 시 모델을 내려 GPU 메모리를 반환합니다.

다른 PC에서 설치
- Windows x64, Python 3.12, 최신 Vulkan 지원 NVIDIA 드라이버가 필요합니다.
- 현재 모델 실행기는 RTX 2080 계열을 선택하며, 없으면 AI 오류를 표시하고 그래픽은 계속 실행됩니다. CPU로 조용히 전환하지 않습니다.
- CLIKA 프로젝트에서 ClikaRT 0.6.4 Windows Python 3.12 wheel을 내려받으세요.
- 본인이 사용할 수 있는 CLIKA 라이선스 파일을 Downloads/Default_Project_license.txt에 둡니다.
  다른 경로는 실행 전 PowerShell에서 $env:CLIKA_RT_LICENSE='라이선스 파일 전체 경로'로 지정합니다. 키 내용이 아닌 경로입니다.
- PowerShell에서 .\모델_설치.ps1 실행. 지정 버전 SDK SHA-256을 확인하고 약 4.55 GB 모델을 다운로드합니다.
- 이후 하늘마루_실행.cmd 실행. 모델 가중치는 Git에 들어 있지 않습니다.

휴대폰 Android 앱
- android-usb/dist/haneulmaru-v5-usb.apk 설치. V4와 다른 패키지라 함께 설치할 수 있습니다.
- PC와 같은 Wi-Fi/노트북 핫스팟에 연결합니다.
- PC가 표시한 최신 QR 링크 전체(https://.../phone#접속코드)를 앱 주소칸에 붙여넣고 V5 연결을 누릅니다.
- 웹 화면에서 PC 연결 시작. PC 지형 탭을 앞에 띄워 두세요.
- 직접 이동: 기본 SIM 드론 선택 → 이동을 직접 이동으로 변경 → 탑승 시점 자동 전환. 왼쪽은 전진/후진/좌측/우측, 오른쪽은 상승/하강입니다.
- 양손을 동시에 사용할 수 있고, 손을 떼거나 앱이 백그라운드로 가면 멈춥니다. IMU는 시선을 바꾸며 이동 버튼과 함께 사용합니다.
- 몰입 화면에도 이동 패드가 남습니다. 자동 관찰 복귀를 누르면 패드가 사라집니다.
- 기존 V5 APK는 서버의 새 웹 화면을 읽습니다. 서버 업데이트 후 앱에서 재연결하면 되며 APK 재설치는 필요하지 않습니다.
- 앱 화면에서도 LOCAL + CLIKA 설정 제안/성능 설명을 사용할 수 있습니다. 모델은 PC에서만 실행합니다.
- NU40를 C-to-C로 연결하고 USB 연결 → Android USB 권한 허용. CDC 형식과 IMU 패킷이 맞아야 합니다.
- USB/IMU가 없거나 끊겨도 터치 조작과 합성 장면은 계속 사용할 수 있습니다.
- 앱 다운로드 링크는 PC 연결 패널과 /android-app.apk에도 있습니다.

선택 모델과 역할
- Qwen/Qwen3.5-2B, Apache-2.0. model-selection.json에 버전·해시 고정.
- ClikaRT 0.6.4, Windows Vulkan, FP16. 이 SDK의 Windows CUDA 백엔드는 비활성입니다.
- 자연어 → 제한된 장면 설정 JSON. 객체 수, 품질, 속도, 조명, 2D/3D, 일시정지만 지원합니다.
- 모델 응답은 서버와 브라우저에서 검증하고 사용자가 적용을 눌러야 반영합니다.
- 한국어 장면 설정 20문장 중 16문장에서 정확한 설정을 반환했습니다. 특히 유지·부정·복합 요청에는 오답이 남아 제안 값을 확인해야 합니다.
- 실패한 JSON은 적용하지 않습니다. 짧고 구체적으로 다시 요청하세요.
- 실제 객체 탐지 모델이나 YOLO 모델이 아닙니다. 합성 게임 난수 분류는 기존 구조를 유지합니다.

연결 구조
NU40 USB → Android 앱 → 인증된 PC HTTP 센서 API → PC 카메라 시점
휴대폰/PC 자연어 입력 → PC 요청 큐 → ClikaRT/Qwen(Vulkan RTX) → 설정 제안 → 사용자 적용
PC Three.js/WebGL 렌더링 → WebRTC 영상 → 휴대폰
폰 조작·적용 설정 → WebRTC 데이터 채널 → 같은 PC 장면

Local의 범위
AI 추론과 3D 렌더링은 PC에서 처리합니다. AWS 서비스는 사용하지 않습니다.
초기 SDK/모델 다운로드, CLIKA 라이선스 검증, 현재 HTTPS Cloudflare 터널은 인터넷이 필요할 수 있습니다.
WebRTC는 같은 LAN에서 직접 연결하며 공유 Wi-Fi의 단말 격리 설정이 있으면 노트북 핫스팟을 사용하세요.
따라서 현재 배포는 완전 오프라인 구성이 아닙니다. APK 안에는 모델이나 라이선스가 없습니다.

검증과 성능 해석
- RTX 2080 Ti에서 실제 CLIKA 모델 로딩·장면 JSON 생성 확인.
- 업데이트된 모델 첫 로딩 약 8초, 12문항 응답 중앙값 약 0.41초. 실행 중 API 단발 검증은 578ms였습니다.
- 이 시간은 모델 응답 시간이며 3D FPS나 휴대폰 전체 지연 시간이 아닙니다.
- CLIKA 언어 모델과 Three.js 그래픽은 GPU 사용 경로가 다릅니다. 동시에 사용하면 자원을 경쟁합니다.
- 브라우저에 Microsoft Basic Render Driver가 표시되면 전용 RTX 실행 창을 사용하세요.
- Android APK 빌드·서명과 PC/HTTP/JS 검증 완료. 실제 휴대폰 설치 및 NU40 실물 종단 간 테스트는 별도 확인이 필요합니다.
- 결과 및 상세 점검은 검증결과.txt 참고.

보안·파일
- 라이선스 원문, SDK wheel, 모델 가중치, 출력 로그, APK 서명 개인키는 Git 업로드에서 제외합니다.
- 서버 재시작 시 접속코드와 터널 주소가 바뀝니다. 이전 QR을 재사용하지 마세요.
- 앱은 최신 Android WebView를 사용하고 카메라·마이크 권한을 요청하지 않는 수신 전용 화면입니다.
- 실행 창 Ctrl+C로 서버·터널·로컬 모델 종료. 전용 Chrome 창은 직접 닫으세요.
