# 하늘마루 V5.1

휴대폰 확대·축소와 QR 주소 직접 입력을 개선한 V5.1 전달본입니다.

- 전체 3D·2D 지도·추적·탑승 시점의 확대·축소
- 센서 사용 중 핀치 줌, 몰입 화면에서도 확대·축소 버튼 제공
- QR 전체 연결 주소 복사·붙여넣기
- PowerShell의 한글 디코딩으로 발생하던 서버 버전 오인 수정

## Android 앱

[최신 APK 다운로드 — 하늘마루 V5.1 USB (5.1.1)](https://github.com/LSB04/haneulmaru/raw/refs/heads/main/V5.1/android-usb/dist/haneulmaru-v51-usb.apk)

기존 V5 USB 앱에 업데이트 설치합니다. PC의 새 QR 전체 주소를 입력한 뒤 **V5.1 연결 → PC 연결 시작**을 누릅니다. PC 지형 탭은 화면에 열어둡니다.

## PC 설치와 실행

1. [먼저읽기.txt](먼저읽기.txt)에서 필수 환경을 확인합니다.
2. Python 3.12와 본인이 사용할 수 있는 CLIKA SDK·라이선스를 준비합니다.
3. `모델_설치.ps1`을 실행해 환경과 모델을 설치합니다.
4. `하늘마루_실행.cmd`로 실행합니다. PC 화면 주소는 `http://127.0.0.1:8795/host`입니다.

모델 가중치(약 4.3 GiB), SDK, 라이선스, 서명 개인키, Python 가상환경은 포함하지 않습니다. 초기 다운로드에는 인터넷이 필요합니다.
