하늘마루 V4 · 합성 드론 게임

V3와 별도 폴더. 실제 탐지/좌표 입력 없이 합성 객체만 사용하는 게임 시각화다.
팀원 저장소의 실제 YOLO 탐지·추적·좌표 코드 및 사진 학습 데이터는 병합하지 않았다.

추가 기능
- 활주로, 유도로, 계류장, 격납고, 관제탑, 터미널로 구성된 가상의 공항 부지.
- 기본 객체는 모두 파랑. 게임 모드에서 미확인 객체가 등장하고 난수로 색상 배정.
- C(초록): 경고와 함께 4초 동안 맵 밖으로 이동한 뒤 퇴장.
- A(파랑): 2초 동안 기존 A에게 합류한 뒤 함께 이동.
- B(빨강): 가까운 A에서 1초짜리 레이저 시각 효과, B 제거 및 게임 점수 증가.
- 레이저와 확산 구체는 고정 시간의 화면 연출이며 실제 무기·유도·피해 계산이 아니다.
- 3D/2D 지도와 드론 탑승/추적 시점. 휴대폰은 PC 화면을 수신하고 같은 게임 상태를 조작.

실행
- 하늘마루_실행.cmd: 서버와 RTX 전용 Chrome 실행. 포트 8794.
- PC 주소: http://127.0.0.1:8794/host
- RTX 2080 Ti가 연결된 상태에서 실행. 장면 · 성능 설정의 GPU 이름 확인.
- 서버가 만든 최신 QR을 휴대폰에서 사용. 기존 V3 QR과 혼용하지 않는다.
- 공항 전경은 전체 3D, 상단 합성 드론 게임 버튼으로 게임 이벤트 시작.
- 미확인 등장 버튼으로 바로 추가, 일시정지와 초기화 사용 가능.
- WASD 이동, Q/E 높이, 좌우 화살표 방향, 드래그 둘러보기.

실제 지도나 특정 공군기지 배치를 재현한 것이 아니다.
게임 결과를 실제 드론의 소속 판정이나 현장 대응 판단으로 사용할 수 없다.

NU40 / IMU 선택 입력
- USB 또는 NU40-IMU BLE의 유효한 데이터 수신 시 IMU 시작 버튼 활성화.
- 350ms 이상 오래된 데이터, 연결 실패, 모델 오류 시 센서 조작만 끄고 터치/마우스와 게임을 유지.
- 장치 재연결 후 IMU 시작을 누르면 다시 사용. 실제 보드 연동은 보드를 연결해 별도 확인.
