구조
PC Three.js/WebGL → canvas.captureStream → WebRTC 비디오 → 휴대폰.
휴대폰 터치/방향/설정 → RTCDataChannel → PC 카메라 및 합성 장면.
Python 표준 HTTP 서버는 정적 파일, SDP/ICE 시그널링, 인증된 로컬 IMU/AWS API를 처리합니다.
NU40 USB NDJSON / BLE UART → Python 최신 샘플 선택 → PC 방향 판별 → 가상 시점 회전.
AR은 폰 카메라 + PC의 녹색 배경 제거 합성입니다. 정밀 공간 앵커 AR은 아닙니다.
소스는 합성 지형/합성 비행체 시각화이며 실제 센서 탐지 또는 위치 복원은 아닙니다.

확인한 것
- 기존 PC Chrome 두 탭에서 영상/조작 전달.
- 1920×1038 및 2560×1384 수신(PC 브라우저 테스트).
- 전송 설정 및 통계 계산 Node 테스트 2개 통과.
- 사용자 휴대폰에서 기존 버전 영상 수신 확인. 이동 시 화질 저하 보고됨.
- 이번 NU40 통합: Node 12개, Python 16개 자동 테스트 통과(2026-10-10).
- USB 우선/BLE 전환/오래된 입력 중단, 타임스탬프 처리, 세션 복구 및 로컬 호스트 인증 확인.
- IMU 버튼을 누르기 전 기존 조작 유지, 입력 끊김 때 조작 해제 확인.

확인하지 못한 것
- 이번 전달본을 다른 PC에서 설치/실행하는 전체 과정.
- 통합본의 실제 NU40 보드 수신·장착 축·감도·USB 분리 체감. 팀원의 이전 실물 수신 보고와 구분합니다.
- 전송 개선 후 실제 휴대폰 이동 화질/지연 측정.
- 팀원 PC의 RTX WebGL 사용과 프레임: 팀원 장치에서 별도 확인 필요.
- 실제 폰 AR 회전/크로마키의 품질과 안정성.

기본 포트8792가 이미 사용 중이면 기존 하늘마루 서버를 확인하세요.
클라우드 GPU는 미연동. Bedrock 장면 설정/측정 설명 코드는 포함되며 각자 단기 키 설정이 필요합니다.
이전 개발 PC에서는 RTX 2080 Ti WebGL 선택과 실제 Bedrock 장면 제안 요청을 확인했습니다.
이번 전달본은 PC 렌더러 탭 숨김/첫 프레임 대기 표시와 로컬 host 세션 복구도 포함합니다.
새 정지사진 데이터셋의 파일/박스/클래스/분할 검증은 1,200장 통과했습니다.
사진 색상은 합성 표식 속성입니다. 학습 정확도나 실물 카메라 성능을 측정한 결과는 아닙니다.
Three.js와 cloudflared의 라이선스는 각 vendor/tools 폴더에 포함됩니다.
